La cámara de tu móvil, conectada a Zeros

El móvil envía imágenes al ordenador, donde se ejecuta el análisis. No se solicita micrófono. Ambos dispositivos deben estar en la misma red local.

Si usas la app desplegada en Railway

Abre directamente su dirección HTTPS e introduce las credenciales de acceso. No necesitas instalar certificados locales, compartir Wi-Fi con el ordenador ni mantener Docker encendido. En En directo, pulsa Usar cámara. Las instrucciones de red local que siguen solo se aplican cuando ejecutas la app en tu ordenador.

Preparar el ordenador para acceso local

Con Docker Desktop iniciado, ejecuta en PowerShell desde la carpeta del proyecto: 

powershell -ExecutionPolicy Bypass -File scripts/Start-Mobile.ps1

El script muestra la dirección de la app. Abre .mobile/access.txt en el ordenador para ver la contraseña y las direcciones específicas de tu red. Si no conecta desde el móvil, ejecuta una vez PowerShell como administrador: 

powershell -ExecutionPolicy Bypass -File scripts/Start-Mobile.ps1 -ConfigureFirewall

Conectar el móvil

  1. Descarga el certificado desde la dirección HTTP que figura en el archivo de acceso. Instala únicamente el certificado generado por tu propia instalación.
  2. iPhone: abre Ajustes → Perfil descargado e instala el perfil. Después, General → Información → Ajustes de confianza de certificados: activa la confianza de esta autoridad local.
    Android: busca Instalar certificado → Certificado de CA en los ajustes de seguridad. El nombre del menú y la confianza del navegador varían según el fabricante.
  3. Abre la dirección HTTPS del archivo de acceso. Introduce el usuario zeros y la contraseña guardada allí. La conexión debe aparecer segura; continuar a pesar de un error de certificado no sustituye la instalación de confianza.
  4. En En directo, pulsa Usar cámara y permite su uso. Se prefiere la cámara trasera; puedes elegir la frontal antes de iniciar.

Encuadrar la mesa

Coloca el móvil en horizontal y fijo, frente al monitor. Una sola mesa, sin reflejos y con texto legible. Usa la previsualización recibida para ajustar las regiones de cartas y números en la configuración de la mesa. Si mueves el móvil o cambias la orientación, detén la captura y calibra de nuevo.

Mantén la pestaña visible y el móvil desbloqueado. Se solicita mantener la pantalla encendida si el navegador lo permite. Ocultar la pestaña detiene la cámara; si se pierde la conexión, el servidor deja de capturar tras 15 segundos sin imágenes.

Detener captura libera la cámara. Puedes detenerla también desde la app en el ordenador. No abras los puertos del router: el acceso está preparado para una red local. Si cambia la IP del ordenador, ejecuta otra vez el script. Puedes retirar el certificado del móvil cuando dejes de usar esta instalación.

La cámara funciona como entrada de vídeo; su precisión sobre una mesa real todavía debe validarse. En dinero real se mantienen las restricciones de revisión posteriores a la sesión.
